## Overview

Oros Fundus is a background-independent relational unification framework
built on a single foundational principle: **information is relational**.
The mathematical realization is a Type III₁ von Neumann algebra as the
bulk, with the Coherence Law derived as a pure theorem of Tomita-Takesaki
theory — not an axiom.

From one environmental integration constant (Λ_UV) and zero free
parameters, the framework derives:

- Einstein Field Equations
- N_g = 3 fermion generations
- N_F = 96 fermionic degrees of freedom
- Pati-Salam algebra (uniquely forced by three simultaneous constraints)
- α_G = π/96, α_s = π/6
- Full Cornell potential V(r) = −α_s/r + σr
- One-loop QCD beta function β₀ = (11N_c − 2N_f)/12π
- Color confinement from Albert's theorem
- Ryu-Takayanagi formula
- H₀ ≈ 68.6 km/s/Mpc, S₈ tension resolution
- Dark energy equation of state w_eff ≈ −1.027

Each script is self-contained and derives a single constant from first
principles. To verify all constants simultaneously:

```bash

```

Or individually:

```bash

python verification/alpha_s.py
python verification/eta_opt.py
```

## Part 2: DESI Phantom Crossing Simulation

Demonstrates that applying the linear CPL parameterization to mock BAO
data generated by the framework's logarithmic w(τ) baseline consistently
recovers the apparent phantom crossing reported in recent DESI analyses.
The crossing is a parameterization artifact, not a physical transition.

```bash
python companion/mock_fit.py
```

Three scenarios are simulated:

| Scenario | Description | Recovered w₀ | Recovered wₐ |
|----------|-------------|--------------|--------------|
| 1 | Pure baseline, no noise | −1.0268 | −0.0054 |
| 2 | Realistic 1.5% noise | −0.9386 | −0.3430 |
| 3 | Dataset tension (DESI regime) | −0.7517 | −1.1045 |

Scenario 3 recovers the characteristic DESI DR2 crisis parameters
(w₀ ≈ −0.75, wₐ ≈ −1.17) from a strictly monotonic phantom baseline
with no true crossing.

## Part 3: Interactive Notebooks

Two Jupyter notebooks provide interactive visualizations of the
framework's cosmological predictions. Select **Run All Cells**
to generate the interactive Plotly dashboards locally.

**`notebooks/phantom_crossing.ipynb`**
Interactive visualization of the CPL parameterization artifact.
Includes a dataset tension slider (0%–100%) showing the crossing
emerging continuously from zero tension. Live readout of w₀ and wₐ
as tension is varied.

**`notebooks/tension_resolution.ipynb`**
H₀ and S₈ tension dashboard. Shows the systematic separation between
internal rulers (distance ladder) and geometric baseline rulers
(BAO/CMB), with the framework's predicted values indicated.
